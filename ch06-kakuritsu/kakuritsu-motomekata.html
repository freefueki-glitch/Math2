２時間目　実験によらない確率の求め方を考える

前の時間：実験をくり返すと、相対度数は一定の値に近づく。この値を確率という。
でも、確率を知るために、毎回何百回も実験をするのは大変…。
実験をしなくても、確率を求められないだろうか？
袋の中（同じ大きさ・形・重さ）
袋の中に、赤球が3個、白球が2個入っている。
よくかき混ぜて、見ないで1個取り出すとき、赤球が出る確率はいくつだろう？　予想してみよう。

「同様に確からしい」とは

同様に確からしい：どの結果が起こることも、同じ程度に期待できること。
（どれかが特に起こりやすい、ということがない）
同様に確からしい例
・ふつうのさいころの目 1〜6
・よくかき混ぜた袋から、見ないで球を取り出す（球は同じ大きさ・形・重さ）
・ふつうのコインの表と裏
同様に確からしくない例
・どれかの面が出やすいように細工したさいころ
・1個だけ大きい球が入っている袋から、さわって取り出す
・（平たい）ボタンを投げて、表と裏のどちらが出るか
これから学ぶ確率の求め方は、「どの場合も同様に確からしい」ときだけ使える。

確率の求め方

起こりうる場合が全部で n 通りあり、どの場合が起こることも同様に確からしいとする。
そのうち、ことがら A の起こる場合が a 通りのとき、
A の起こる確率 p ＝ an ＝ ことがら A の起こる場合の数起こりうるすべての場合の数
たとえば、さいころを投げて1の目が出る確率は、
起こりうる場合が 1,2,3,4,5,6 の6通り、1の目が出るのは1通りだから、16。
前の時間の実験で、相対度数が約 0.167 に近づいたのと同じ値になる！

例題：球を取り出す

袋に、赤球3個と白球2個が入っている。1個取り出すとき、赤球が出る確率は？
袋の中
① すべての場合
球に番号をつけて区別すると、取り出し方は ①〜⑤の5通り。
どの球が出ることも同様に確からしい。
② 赤球が出る場合
赤球は①②③なので、3通り。
③ 確率
p ＝ 35　（赤球が出る確率は 35）
答え：35　（0.6にあたる）

実験でたしかめてみよう

本当に 35＝0.6 に近づくのか、赤球・白球を何度も取り出して調べよう。　（取り出した球は、毎回袋にもどす）

練習：同じ袋で考えよう

袋の中（赤球3個・白球2個）
(1) 白球が出る確率は？25　（白球は2通り／全部で5通り）
(2) 赤球または白球が出る確率は？55 ＝ 1　（5通りすべて）
(3) 青球が出る確率は？05 ＝ 0　（青球は入っていない）
(2)と(3)の答えには、どんな特ちょうがあるだろう？

かならず起こる・けっして起こらない

赤球だけが5個入った袋
赤球が出る確率 ＝ 55 ＝ 1
→ かならず起こることがらの確率は 1
白球が出る確率 ＝ 05 ＝ 0
→ けっして起こらないことがらの確率は 0
身近な例
・さいころを投げて、7の目が出る　→　確率 0
・さいころを投げて、1〜6のどれかが出る　→　確率 1
・ジョーカーを抜いたトランプ52枚から1枚ひいて、ジョーカーが出る　→　確率 0

起こる場合の数 a は 0 から n までの値だから、確率 an も 0 から 1 までの値になる。

まとめ

  • ①同様に確からしい：どの結果が起こることも、同じ程度に期待できる。
  • ②どの場合も同様に確からしいとき、
    確率 p ＝ ことがらAの起こる場合の数 ÷ 起こりうるすべての場合の数
  • ③かならず起こることがらの確率は 1、けっして起こらないことがらの確率は 0。
  • ④確率 p は、いつも 0 ≦ p ≦ 1 の範囲の値になる。
