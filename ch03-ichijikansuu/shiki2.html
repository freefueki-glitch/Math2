① グラフを使わずに式を求める

一次関数の式 y＝ax＋b は、次のいずれかが分かれば、グラフをかかなくても求めることができる。
  • ◆傾きaと、通る1点の座標がわかっているとき
  • ◆切片bと、通る1点の座標がわかっているとき
  • ◆2点の座標がわかっているとき
どの場合も、代入して式を組み立てていく。この3つのパターンを練習しよう。

② 傾きと1点の座標がわかっているとき

1y＝ax＋b に、わかっている傾きaと通る点の座標を代入する。
2bについての方程式を解く。
3求めた a と b を、y＝ax＋b にあてはめる。
例題
傾きが3で、点(2, 4)を通る一次関数の式を求めよう。

y＝3x＋b に x＝2, y＝4 を代入する
4＝3×2＋b
4＝6＋b
b＝4−6＝−2

→ 式は y＝3x−2

③ 切片と1点の座標がわかっているとき

1わかっている切片bを、y＝ax＋b の b にそのまま入れる。
2通る1点の座標を代入する（bはすでにわかっているので、aだけの方程式になる）。
3aについての方程式を解く。
4求めた a と b を、y＝ax＋b にあてはめる。
例題
切片が1で、点(3, 7)を通る一次関数の式を求めよう。

y＝ax＋1 に x＝3, y＝7 を代入する
7＝3a＋1
3a＝7−1＝6
a＝2

→ 式は y＝2x＋1
切片bはそのまま使えるので、残りは1つの方程式でaだけを求めればよい。

④ 2点の座標（変化の割合を使う方法）

12点の座標から、
a ＝（yの増加量）÷（xの増加量） で傾きを求める。
2y＝ax＋b に、求めた a とどちらか1点の座標を代入する。
3bについての方程式を解く。
4求めた a と b を、y＝ax＋b にあてはめる。
例題
2点 (1, 5)、(3, 9) を通る一次関数の式を求めよう。

a ＝ (9−5)÷(3−1) ＝ 4÷2 ＝ 2

y＝2x＋b に x＝1, y＝5 を代入する
5＝2×1＋b
b＝5−2＝3

→ 式は y＝2x＋3
代入する点は、(1, 5)でも(3, 9)でもどちらでもよい。同じ式になることを確かめてみよう。

⑤ 2点の座標（連立方程式を使う方法）

12点の座標をそれぞれ y＝ax＋b に代入し、2つの式をつくる。
2できた2つの式を、連立方程式として解く（ひき算でaかbを消去する）。
3求めた a を、どちらかの式に代入して b を求める。
4求めた a と b を、y＝ax＋b にあてはめる。
例題
2点 (1, 5)、(3, 9) を通る一次関数の式を求めよう。

(1, 5)を代入：5＝a＋b　…①
(3, 9)を代入：9＝3a＋b　…②

②−①：4＝2a → a＝2
①に代入：5＝2＋b → b＝3

→ 式は y＝2x＋3
変化の割合を使う方法と同じ式になることに注目しよう。どちらの方法で解いてもよい。

⑥ まとめ

  • ◆傾きaと1点の座標がわかっているとき → y＝ax＋bに代入してbを求める。
  • ◆切片bと1点の座標がわかっているとき → bをそのまま使い、1点の座標を代入してaを求める。
  • ◆2点の座標がわかっているとき → 変化の割合でaを求めてから代入する方法と、連立方程式で解く方法の2通りがある。
  • ◆どの場合も、最後は y＝ax＋b の形にまとめる。
