1思考・判断・表現
(1)右の図で、ℓ // m のとき、∠x の大きさを求めなさい。
∠x＝75°
折れ線の頂点を通り、ℓ に平行な直線をひく。 錯角が等しいので ∠x＝34°＋41°＝75°
(2)右の図のように、5本の線分で星形の図形をつくった。∠A＝42°、∠B＝35°、∠C＝28°、∠D＝40° のとき、∠E の大きさを求めなさい。
∠E＝35°
星形の先端の5つの角の和は 180°。 ∠E＝180°−(42°＋35°＋28°＋40°)＝35°
(3)△ABC の内角の和が 180° であることの説明です。ア・イ・ウにあてはまる言葉や数を答えなさい。 辺BCをCの方へ延長して点Dをとり、点Cを通り辺BAに平行な直線CEをひく。 AB // CE だから、∠BAC＝∠ACE　……　（ア）が等しい 　　　　　　　　∠ABC＝∠ECD　……　（イ）が等しい したがって　∠BAC＋∠ABC＋∠ACB＝∠ACE＋∠ECD＋∠ACB＝（ウ）°
ア：錯角　イ：同位角　ウ：180
∠ACE＋∠ECD＋∠ACB は一直線の角 ∠BCD になるので 180°。 平行線の性質を使うと、3つの角を1か所に集められる。
2思考・判断・表現
(1)線分ABと線分CDは点Oで交わっていて、AO＝BO、CO＝DO です。AC＝BD であることの証明で、ア〜ウにあてはまる言葉を答えなさい。 ［証明］△AOC と △BOD において、 仮定より　AO＝BO　……①　　CO＝DO　……② （ア）は等しいから　∠AOC＝∠BOD　……③ ①、②、③より、（イ）が、それぞれ等しいので　△AOC≡△BOD したがって、AC＝BD　（ウ）ので。
ア：対頂角　イ：2組の辺とその間の角　ウ：合同な図形の対応する辺は等しい
①②で2組の辺、③で「その間の角」が等しいことがそろう。
(2)AB // DC で、線分ADと線分BCは点Oで交わっていて、AO＝DO です。BO＝CO であることを証明しなさい。
［証明］
△ABO と △DCO において、 仮定より　AO＝DO　……① 対頂角は等しいから　∠AOB＝∠DOC　……② AB // DC で、錯角は等しいから　∠BAO＝∠CDO　……③ ①、②、③より、1組の辺とその両端の角が、それぞれ等しいので　△ABO≡△DCO 合同な図形の対応する辺は等しいから　BO＝CO ポイント：平行線があるときは、錯角（同位角）が等しいことを使えないか考える。
3思考・判断・表現　折り返し

長方形ABCDの紙を、線分EFを折り目として折り返した。頂点D、CがそれぞれD′、C′に移り、∠AED′＝50° である。

(1)∠DEF の大きさを求めなさい。
∠DEF＝65°
折り返しだから ∠DEF＝∠D′EF。 ∠DEF＋∠D′EF＝180°−50°＝130° より ∠DEF＝65°
(2)∠EFC の大きさを求めなさい。
∠EFC＝115°
AD // BC より、同側内角の和は 180° なので ∠EFC＝180°−65°＝115°
(3)∠DEF ＋ ∠EFC ＝ 180° となる理由を、平行線の性質を使って説明しなさい。
（模範解答）
AD // BC で、錯角は等しいから ∠DEF＝∠EFB。 また ∠EFB＋∠EFC＝180°（一直線）。 よって ∠DEF＋∠EFC＝180° となる。
4思考・判断・表現　くぼみのある四角形

くぼみのある四角形ABCDがある。BCを延長した直線とADとの交点をEとする。

(1)∠BAD＝44°、∠ABC＝28°、∠ADC＝33° のとき、∠x の大きさを求めなさい。
∠x＝105°
∠x＝∠BAD＋∠ABC＋∠ADC＝44°＋28°＋33°＝105°
(2)∠x＝∠BAD＋∠ABC＋∠ADC となることを説明しなさい。
（模範解答）
△ABE で、外角の性質より　∠CED＝∠BAD＋∠ABC　……① △CDE で、外角の性質より　∠x＝∠CED＋∠ADC　……② ①を②に代入して　∠x＝∠BAD＋∠ABC＋∠ADC （辺ADをのばして考えるなど、別の説明でも正解）
