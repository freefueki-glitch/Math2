1思考・判断・表現　二等辺三角形の底角
△ABC は AB＝AC の二等辺三角形です。∠A の二等分線と辺BC の交点を D とするとき、∠B＝∠C の証明の（ア）（イ）にあてはまる言葉を答えなさい。 ［証明］△ABD と △ACD において、 仮定より　AB＝AC　……①　∠BAD＝∠CAD　……② 共通な辺だから　AD＝AD　……③ ①、②、③より、（ア）が、それぞれ等しいので　△ABD≡△ACD 合同な図形の（イ）は等しいから　∠B＝∠C
ア：2組の辺とその間の角　イ：対応する角
①の辺AB・ACと③の辺AD、そして②の「間の角」がそろうので、2組の辺とその間の角が等しい。 合同な図形では、対応する辺・角が等しい。
2思考・判断・表現　平行四辺形になることの証明
平行四辺形ABCDの対角線BD上に、BE＝DF となる点E、Fをとります。このとき、四角形AECF が平行四辺形になることを証明しなさい。 （ヒント）対角線ACとBDの交点をOとして、「対角線がそれぞれの中点で交わる」ことを使う。
［証明］
対角線ACとBDの交点をOとする。 平行四辺形の対角線は、それぞれの中点で交わるから　AO＝CO　……①　BO＝DO　……② 仮定より　BE＝DF　……③ ②、③より　EO＝BO−BE＝DO−DF＝FO　……④ ①、④より、対角線がそれぞれの中点で交わるので、四角形AECF は平行四辺形である。 ポイント：平行四辺形になることを証明するときは、5つの条件のうち「どれを使うか」を最初に決める。
3思考・判断・表現　角の二等分線と二等辺三角形
平行四辺形ABCDで、∠A の二等分線が辺BC と交わる点を E とします。このとき、BA＝BE であることを説明しなさい。
［説明］
AD // BC で、錯角は等しいから　∠DAE＝∠AEB　……① 仮定より　∠BAE＝∠DAE　……② ①、②より　∠BAE＝∠AEB 2つの角が等しいので、△BAE は二等辺三角形である。 したがって　BA＝BE
4思考・判断・表現　二等辺三角形の利用
AB＝AC の二等辺三角形ABCで、辺AB、AC 上に BD＝CE となる点D、Eをとり、BE と CD を結びます。このとき、BE＝CD であることを証明しなさい。
［証明］
△DBC と △ECB において、 仮定より　BD＝CE　……① AB＝AC より、二等辺三角形の底角は等しいから　∠DBC＝∠ECB　……② 共通な辺だから　BC＝CB　……③ ①、②、③より、2組の辺とその間の角が、それぞれ等しいので　△DBC≡△ECB 合同な図形の対応する辺は等しいから　CD＝BE
5思考・判断・表現　面積が等しい三角形（等積変形）

台形ABCDは、AD // BC で、対角線ACとBDの交点を O とします。

(1)△ABC と面積が等しい三角形を答えなさい。
△DBC
底辺BC が共通で、AD // BC なので高さが等しい。だから △ABC＝△DBC
(2)△ABO と面積が等しい三角形を答えなさい。
△DCO
(1)と同じ考えで △ABD＝△ACD。 両方から共通部分の △AOD をひくと △ABO＝△DCO
(3)(2)でそのように考えた理由を、(1)の結果を使って説明しなさい。
（模範解答）
AD // BC だから、底辺を共通にする △ABC と △DBC は面積が等しい…の考えから、△ABD＝△ACD。 両方から共通部分の △AOD をひくと、△ABO＝△DCO となる。
